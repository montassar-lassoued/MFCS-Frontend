# MFCS Frontend – IntraConnect UI 🚀

[![Angular](https://img.shields.io/badge/Angular-17.3.17-DD0031?style=for-the-badge&logo=angular&logoColor=white)](https://angular.io/)
[![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=for-the-badge&logo=typescript&logoColor=white)](https://www.typescriptlang.org/)

Das **MFCS-Frontend** ist die zentrale Benutzeroberfläche zur Steuerung, Überwachung und Analyse eines **Material Flow Control Systems (MFCS)**. Es ermöglicht die transparente Visualisierung und operative Kontrolle von Materialflüssen innerhalb automatisierter Logistik- und Produktionsumgebungen.

> **Hinweis:** Das Projekt steht noch am Anfang seiner Entwicklung. Es wird laufend modernisiert und funktional ausgebaut.

## 📖 Projektübersicht

Dieses Projekt bietet eine intuitive Oberfläche für das "IntraConnect"-System, um komplexe Materialflüsse in Echtzeit zu managen. Es wurde mit dem **Angular CLI** (Version 17.3.17) entwickelt und legt Wert auf Performance und Skalierbarkeit.

### ✨ Kernfunktionen
- **Echtzeit-Überwachung:** Visualisierung von laufenden Materialflüssen.
- **Systemsteuerung:** Zentrale Verwaltung der automatisierten Logistikkomponenten.
- **Analyse-Tools:** Werkzeuge zur Auswertung und Optimierung der Abläufe.
- **Responsive UI:** Optimiert für die Nutzung in Leitständen.
